# Retain validated outputs with registry acceptance

Each accepted input-changing registry update records its complete inputs,
generated supergraph, public API schema, reports, and publication receipt in
the same conditional Git commit. Publication already composes before accepting
the graph; retaining that result binds acceptance to the generated bytes and
removes the later artifact-generation recovery phase.

Git is the authoritative store for these accepted snapshots. Immutable GitHub
releases distribute the recorded bytes without recomposition; a failed release
upload does not undo acceptance or lose its artifact. This supersedes the
generation and storage direction in [ADR 0006](0006-publish-immutable-release-artifacts.md),
while preserving its policy of no automatic expiry or pruning for published
artifacts and applying that policy to accepted snapshots and their receipts.
Deliberate operator deletion remains outside Selvedge. Gateway activation still
requires explicit artifact selection under
[ADR 0004](0004-explicit-artifact-activation.md).

Every accepted input-changing path, including maintainer configuration changes,
must preserve the matching input/output snapshot. Maintainer ownership and
source-repository approval policies remain intact. Control changes use the
shared finalizer under [ADR 0013](0013-finalize-approved-controls-through-the-shared-publisher.md);
its concrete GitHub workflow and the artifact retrieval interface remain to be
specified. Generated output and retained receipts increase Git history, and
durability depends on preserving accepted history and its reachable objects.
